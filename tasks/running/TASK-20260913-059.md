# TASK-20260913-059 — Daily Zero-Cost Football Intelligence Dataset

## 目标

建立与生产模型完全隔离的、追加式、可追溯的 point-in-time 足球数据采集基础设施，新增外部数据成本保持为 0 欧元/月。

## 允许范围

- 审计公开数据源、许可、robots 和自动化条件。
- 实现 provider-neutral collector、缓存、限速、原始归档、标准化、去重、新鲜度检测、来源健康、fixture/team matching。
- 实现明确允许自动化的零成本 adapter，以及官方来源证据的人工输入 adapter。
- 使用公开来源执行低频隔离 Canary。
- 编写测试、文档、报告并提交研究分支。

## 禁止范围

- 生产数据库写入、migration、backfill。
- 生产部署或 Windows Scheduler 变更。
- 付费 API、付费数据集、绕过登录/付费墙/CAPTCHA/Cloudflare。
- 模型优化或新增投注规则。
- 修改任何 Frozen 项或现有 90% completeness gate。

## 验收

- 每条 observation 包含 fixture_id、source、source_url、published_at、captured_at、raw_payload_hash、parser_version、data_type、source_policy。
- 原始存储追加写入；同一 observation 幂等。
- 合规来源有缓存、限速、请求预算、stale 和 parser regression 测试。
- 隔离 Canary 成功，并形成 `DAILY/T-24H/T-6H/T-90/T-60/T-30/POST_MATCH` 明确计划。
- 在 Production Data Collection Approval Gate 停止。

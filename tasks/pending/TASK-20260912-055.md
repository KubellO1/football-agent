# TASK-20260912-055 — Zero-Cost Longitudinal Dataset Acquisition & Model Validation

## 目标

在新增外部数据成本为 €0 的前提下，获取、验证并标准化五大联赛多赛季纵向数据，并原样复用 TASK-20260904-054 baseline runner 进行严格的时序样本外验证。

## 允许范围

- 审计 Football-Data.co.uk 及其他合法开放纵向数据源。
- 使用无需登录、无需绕过访问控制的官方公开 CSV/JSON 下载。
- 新增 research-only adapter，包含缓存、校验和、parser version 与 provenance。
- 在隔离本地 artifact 中标准化球队、联赛、赛季和 fixture identity。
- 调用未修改的 TASK-054 runner 完成 A–F baseline、消融、校准与赔率目标评估。
- 新增测试、报告、提交、远程分支和 PR。

## 禁止范围

- 不修改 TASK-054 baseline runner。
- 不写入 Production PostgreSQL。
- 不运行 production jobs，不修改 Windows Scheduler。
- 不购买 API、代理、数据集或抓取服务。
- 不合并 master，不部署。
- 不修改 Frozen 规则或 production 90% completeness gate。

## 验收标准

- 五大联赛、多个赛季、连续球队历史可复现。
- 5/10/20 场滚动窗口及 chronological OOS split 无未来信息泄漏。
- provider ID 与自然键去重后 fixture duplicate = 0。
- xG 缺失保持 NULL，绝不用 goals 代替 xG。
- 历史赔率作为独立 target-evaluation 数据，明确 opening/closing 语义。
- 报告 Brier、Log Loss、calibration、accuracy、OOS ROI、signal count、联赛与赛季稳定性；证据不足时必须明确说明。

## 停止条件

交付整合后的来源审计与模型验证报告。任何 production 变更继续受单独 Approval Gate 约束。

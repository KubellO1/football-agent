# TASK-20260927-080 — Protect Docker Build Context from Secrets

## Objective

Ensure credentials, database dumps, forensic archives, and local runtime state
cannot enter Docker image layers through the repository build context.

## Change

- Add an explicit `.dockerignore` for `.env` variants and sensitive artifacts.
- Keep the non-secret `.env.example` manifest available to the build context.
- Add a contract test for required exclusion patterns.

## Safety

- No credentials are read, copied, or committed.
- No production database or Scheduler change.
- No application/Frozen behavior change.

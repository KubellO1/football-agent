# TASK-20260904-053 — Marvis Zero-Cost Mode Architecture

## Objective

在 `NEW_PAID_PROVIDER_BUDGET = €0` 的硬约束下，盘点可合法继续使用的数据资产，设计研究数据集、零成本特征集、独立实验模型、免费实时模式与人工输入接口。

## Allowed scope

- 只读审计仓库、既有任务报告和可访问的本地研究资产。
- 查阅官方开放数据、免费官方 API 和公开下载来源的许可与能力。
- 创建文档、JSON 规范、任务报告与 handoff。
- 设计但不接入 `ZERO_COST_FEATURE_SET_V1` 与 `MARVIS_ZERO_COST_V1`。

## Prohibited scope

- 不购买或联系任何付费数据供应商。
- 不修改生产模型、完整度公式、阈值、Gate、EV、Confidence、Kelly、alpha、白名单或投注决策规则。
- 不修改生产代码、配置、数据库、Schema、Scheduler 或部署状态。
- 不运行生产任务、backfill 或赔率请求。
- 不把 research-only 数据计入生产实时完整度。

## Approval gate

完成审计、架构设计、报告与本地提交后 STOP，等待是否实施隔离研究数据集与实验运行器的明确批准。

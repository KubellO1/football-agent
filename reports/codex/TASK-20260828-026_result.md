# TASK-20260828-026 Result

## Outcome

Odds-API.io 的三向足球 moneyline 现在只在 provider normalization 边界转换为内部 canonical `h2h`。下游 ingestion 未增加临时兼容逻辑，仍严格只接受 `h2h`。

## Root cause and fixed data flow

修复前：

```text
Odds-API.io ML
→ OddsApiIoProvider 输出 market=1x2
→ fixture 成功匹配
→ OddsIngestionService 只接受 h2h
→ bookmaker/snapshot 创建前静默丢弃
```

修复后：

```text
Odds-API.io 精确三向 moneyline 别名
→ OddsApiIoProvider normalization 输出 market=h2h
→ fixture 成功匹配
→ ingestion market validation
→ bookmaker boundary
→ home/draw/away snapshot persistence boundary
```

## Exact implementation

- 修改层：`OddsApiIoProvider` normalization boundary。
- canonical key：`h2h`。
- 经过大小写和空白规范化后，仅接受：`1x2`、`h2h`、`ml`、`moneyline`、`money line`。
- `double chance`、`draw no bet`、`DNB`、`asian_handicap`、`totals` 明确拒绝。
- 未知市场记录 reason code：`ODDS_API_IO_UNSUPPORTED_MARKET`。
- provider stats 增加可审计计数：`markets_rejected_unsupported`。
- home/draw/away 的名称、顺序和 decimal price 保持不变。

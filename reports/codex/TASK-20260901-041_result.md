## Provider Health `providers=0/0`

这不是简单 renderer 文案错误，未在本任务修复。

- Dashboard 与 canonical worker 都读取 `data/provider_health.json`。
- clean release runtime 中该文件不存在。
- canonical `provider_health` worker 只检查 PostgreSQL并读取该文件，不主动探测
  provider；文件缺失时自然得到 `providers=0/0`。
- legacy `app/scheduler_runner.py` 存在写入该文件的另一套流程，而当前
  `scripts/health_check.py` 输出到 `output/health_check_*.json/md`，两者契约不一致。

因此根因是 **Provider Health producer/consumer contract 与计划任务拓扑不一致**，
应建立独立任务修复，不能混入本次球队名称修复。

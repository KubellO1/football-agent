## Second-run safety audit

No second production run was performed.

Static repository/natural-key behavior shows:

- Fixtures are replay-safe through `external_source + external_id` lookup and uniqueness.
- Teams, competitions, and bookmakers are replay-safe through provider external identity.
- Odds snapshots use `uq_odds_snapshots_natural` with `ON CONFLICT DO NOTHING`.
- Prediction decision rows are **not replay-safe** for the observed no-selection path.

`DailyTopPicksService` calls `log_fixture_predictions` for each eligible fixture before its
decision-log skip. When analysis has no selections, `log_fixture_predictions` unconditionally adds
a new UUID prediction row. The predictions table has no matching natural unique constraint.
Therefore, another daily run for the same date would append another `WATCH` row for each of these
two fixtures.

This is the blocking reason recurring DailyProductionRun remains disabled.

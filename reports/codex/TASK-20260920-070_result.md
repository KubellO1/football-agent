Critical timestamp distinction: Pinnodds explicitly says top-level `last` is a change cursor and event-level `last` is response render time, **not** an individual price-update time. Its odds payload has no per-event update timestamp. PinnWire documents `generated_at` as response time, not a per-market price-change time. Therefore `source_timestamp=unavailable`; only the real HTTP observation time may become `captured_at`. Never rename a serve/cursor timestamp as bookmaker last update.

## Code/data-flow audit

- `app/providers/interfaces/odds_provider.py` and `app/providers/schemas/odds.py` provide a swappable odds interface and normalized event DTO, but the market DTO only has `last_update`, not separate observation/source times or hash/parser provenance.
- `app/services/odds_ingestion.py` **skips every market with `last_update=None`** and uses `last_update` as snapshot `captured_at`. `app/providers/impl/prioritized_odds_provider.py` also requires non-NULL `last_update` before counting primary coverage. A direct adapter using truthful `source_timestamp=None` would thus produce zero persisted odds. Falsely filling `last_update` from the HTTP clock would misstate its meaning. This needs a separately tested observation-time contract change before wiring.
- `app/repositories/sqlalchemy/odds_snapshot_repository.py` has PostgreSQL conflict-safe insert on fixture/bookmaker/market/selection/line/captured_at. Replaying the *same saved observation* can be idempotent; a new actual HTTP capture is a new point-in-time observation, even if its price is unchanged. A content hash/collector identity for raw replay is not yet part of production schema.
- `app/services/odds_ingestion.py` currently stores a fixed bookmaker external-source namespace; the canonical `pinnacle` key can be shared by both technical feeds only after cross-provider row-resolution tests. `provider_source` belongs to the snapshot, not the bookmaker.
- `app/config/settings.py` keeps `analysis_odds_min_bookmakers=2`; two technical Pinnacle feeds still yield **one** independent bookmaker. No VERIFIED quote or BET may be inferred from them alone. Frozen policy remains unchanged.
- TASK-069 read-only production audit found zero country-qualified upcoming five-league fixtures at that time. A naturally eligible production canary must recheck current fixtures before any request or write.

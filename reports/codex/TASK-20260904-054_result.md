# TASK-20260904-054 结果报告

## 结论

当前证据不足以证明“仅依赖新增成本为 €0 的数据”可以训练出具有实际预测价值的五大联赛模型。结论是数据不足，不是模型失败：已核验的 TASK-051 StatsBomb Open Data 样本只有 10 场、37,137 条事件，适合验证 PPDA、定位球射门和头球射门等事件契约，但无法为各球队构造连续 5/10/20 场历史窗口。

因此本轮没有计算虚假的 Brier、Log Loss、校准或 ROI，也没有把稀疏样本包装成可泛化结论。

## 实现范围

Runner 使用标准库实现固定、可解释的 Poisson-style baseline：

- A：goals + recent form
- B：A + home/away
- C：B + xG/xGA
- D：C + shots/SOT
- E：D + possession/saves/conversion
- F：E + research-only event features

它实现了 fixture 去重、provider ID 冲突检测、同联赛同赛季历史隔离、严格早于目标 kickoff 的时序校验、chronological 60/20/20 split、按五大联赛输出，以及 Brier、Log Loss、ECE/calibration bins、accuracy 和 ablation。

## Implementation

The active Alembic graph is now a single linear successor:

```text
settlement_void_0022
  -> team_intelligence_0023
```

The migration creates four tables: reviewed source registry, immutable raw
payload metadata, immutable capture receipts, and immutable normalized
observations. Exact composite foreign keys retain source, source-policy, raw
payload, URL, and capture-time provenance.

PostgreSQL triggers reject `UPDATE`, `DELETE`, and `TRUNCATE` on all three
evidence tables. Insert triggers reject raw payloads, receipts, and observations
whose source is not registered, approved, enabled, and permitted for storage
and automation. `LICENSE_UNCLEAR`, `RESEARCH_ONLY`, and `REJECTED` sources remain
disabled.

The deterministic semantic key excludes `captured_at`. Exact replay and a later
capture of unchanged evidence insert zero observations; a later capture still
preserves a distinct receipt. Changed or conflicting source evidence appends a
new row without mutating history.

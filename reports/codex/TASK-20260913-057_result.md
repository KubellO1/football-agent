## 信号可用性审计

| 信号 | 结论 | 原因 |
|---|---|---|
| Opening → later odds movement | UNAVAILABLE | 没有带可靠时间戳的中间报价序列 |
| Cross-book disagreement | RESEARCH_BENCHMARK_ONLY | 有多家公司报价，但无逐行 captured_at，不能证明实时可重建 |
| Confirmed lineups | UNAVAILABLE | 没有合法、连续、point-in-time 的五大联赛纵向样本 |
| Player absences | UNAVAILABLE | 同上 |
| Official news | UNAVAILABLE | 没有与 fixture 对齐的历史发布时间档案 |
| Rest / congestion | TEMPORALLY_VALID | 仅使用比赛前已完成赛事计算休息天数 |
| Weather | UNAVAILABLE_FOR_THIS_BENCHMARK | 本地缺场地坐标，公开 forecast archive 也未统一覆盖全部三赛季 |
| Post-information movement | UNAVAILABLE | 同时缺信息发布时间和连续报价时间戳 |

[Football-Data.co.uk 下载说明](https://www.football-data.co.uk/downloadm.php)说明较新赛季包含早期采集赔率与 closing 列，但当前 CSV 没有逐行报价采集时间；因此这些价格只能作为研究基准，不能证明某个赛前时点可用。[StatsBomb Open Data](https://github.com/statsbomb/open-data/blob/master/README.md)只覆盖选定赛事且授权定位于研究/公开兴趣，不能补齐本任务所需的五大联赛连续实时信息。公开天气 previous-run archive 也存在模型与起始年份差异，无法覆盖当前完整基准期，[Open-Meteo 文档](https://open-meteo.com/en/docs/previous-runs-api)。
